# このスキルの根拠

| 出どころ | このスキルで使ったこと |
| --- | --- |
| 櫻田潤『図で考える。シンプルになる。』（ダイヤモンド社, 2017） | 7つの図（交換・ツリー・深掘り・比較・段取り・重なり・ピラミッド）。図は関係を見せるもの |
| 櫻田潤『たのしいインフォグラフィック入門』 | 「情報整理7割、デザイン3割」。分かりにくさの多くは、言いたいことがまとまっていないことから来る |
| Dan Roam, *The Back of the Napkin* (2008) | 6つの見方（誰・何／どれだけ／どこ／いつ／どうやって／なぜ）と、それぞれに合う図 |
| Yuri Engelhardt, *The Language of Graphics* (2002) | 図の基本構造：意味のある位置、まとまり、仕切り、並び、線でつなぐ、入れ子、重ね |
| Richard E. Mayer, *Multimedia Learning* (3rd ed., 2020) | 余分を除く（coherence）、構造を目立たせる（signaling）、ラベルを近くに置く（spatial contiguity） |
| 川喜田二郎『発想法』（中公新書, 1967）／KJ法 | ラベル作り → グループ編成（表札）→ 図解化 → 文章化。structure-reading の元 |
| coleam00/excalidraw-diagram-skill | 図は主張する（argue, not display）。関係は必ず線で。同じ箱の格子を避ける。描いたら画像で見て直すループ |
| cathrynlavery/diagram-design | 強調色は1つ。いちばん良い手はたいてい削ること。読み手が文章より多くを学べないなら描かない |
