# ビンテージの気象と総評

`vintages` の3つの欄を、気象データと畑のメモから順に作る。総評は気象の報告ではなく、**ブドウがどう育ったか**の話として書く。

## 0. 設定を読む

🧭 AI設定ページから読む。無いものは利用者に聞く。

| 設定 | 例 |
| --- | --- |
| 気象データの置き場 | 接続表の `weather_daily`（近くのアメダスの日別：平均・最高・最低気温、降水量、日照時間） |
| 平年の基準期間 | 例：直近の10年 |
| 生育期 | 例：4〜10月 |
| 生育ステージの目安 | 自分の地域の開花・ベレゾン・成熟・収穫の時期 |
| 観察の記録 | 接続表の `observations`。あればステージの実際の日を優先する |
| 圃場の呼び名 | 総評の書き出しに使う |
| 生育の知識の参照先 | 自分の知識ページがあれば |

## 1. 計算する

1. 対象の年の日別データを取る
2. 基準期間の平年値を出す
3. 月ごとの集計、平年との差、積算温度の累積を出す
4. 畑のメモ（`vintages` の「畑メモ」）を読む。空なら飛ばす

積算温度（GDD）＝ 生育期の Σ max(日平均気温 − 10℃, 0)。計算式は欄の説明に書き、セルには書かない。

## 2. 気象サマリー

```
【生育期 4–10月／平年比（基準期間）】
平均気温 ○○°C（±○○）／降水量 ○○mm（±○○）／日照 ○○h（±○○）
暑い日（日平均≥25°C）○○日（平年 ○○日）→ 一言

▍開花期（〇月）：気温・降水の実数と平年比、開花への影響を1文
▍成熟期（〇–〇月）：気温・降水・日照の実数と平年比、目立つ月の差
▍特記事項（あれば）：生育期の外の異常気象、鳥害、霜害など
▍総括：3〜5文。畑のメモがあれば、その実感を気象データで裏付ける形で
```

体言止め・簡潔に。数値は小数第1位まで（降水量は整数でよい）。差は（+○○）（−○○）。月の降水は「平年 ○○mm の ○○%」でもよい。

## 3. 積算温度

```
▍月別（累積）
4月：○○ (○○)
…
10月：○○ (○○)
▍シーズン合計：○○（平年 ○○、±○○）
▍特徴：2〜3文。積み方の型（前半集中型／バランス型／後半偏重型）とブドウへの意味
```

## 4. ビンテージ総評

読み手はワインの飲み手（消費者〜バイヤー）。気象の専門家ではない。

### 使う因果の地図

- **温度とステージ**：温度が高いと各ステージが早まる。前半が暑いとベレゾンが早まり、「収穫が早まる」か「成熟の期間が延びる」かは秋の天気次第。積算温度と品種ごとの目安を照らせば、どのくらい早まったか推定できる。観察の記録があれば実データを優先
- **糖**：主に日照（光合成）で増える。暑すぎると、糖だけ先に上がりフェノールや香りが追いつかないことがある
- **酸（リンゴ酸）**：夜温が高いと呼吸で減り、収穫時の酸が下がりやすい。冷涼な地域で酸が保たれるのは夜温が低いから
- **色・フェノール**：極端な高温や高い夜温が続くと色づきが悪くなりやすい。成熟の期間が長いほど、果皮の成分（タンニン・色素・香りのもと）が豊かにたまる
- **積み方の型**：前半集中型は成熟期の天気が品質を左右（雨が少なく日照が良ければ凝縮、雨が多ければ薄まる）／バランス型は均整のとれた熟し方になりやすい／後半偏重型は成熟の期間が短く、秋の天気次第で繊細な年にも不作にもなる
- **雨と日照**：成熟期の多雨は薄まり・腐れ、少雨は凝縮。ベレゾン期の多雨は灰色かび・裂果
- **冷涼地の暖かい年**：ちょうどよければ、ふだん難しいフェノールの成熟まで届き、糖・酸・フェノールの整った年になる。夜温が高すぎると酸が急に落ち、糖だけ高い不均衡な熟し方になる

具体的な温度や日数を総評に書くときは、science-research の基準で資料を確かめる。

### 構成（4〜6文）

- **書き出し**：圃場の呼び名を自然に入れる（「〈圃場〉の〇年は、〜」）
- **① 気候の性格（2文）**：1文目は年全体の性格、2文目は積み方の型とブドウへの意味。数値ではなく言葉で。「GDD」は使わない（「積算気温」はよい）
- **② 生育と収穫（1〜2文）**：春→初夏→成熟期→収穫の時間に沿って、ブドウに何が起きたか。畑のメモの実感を、品種をまたいで使える言い方にする。品種名は出さない。数値より結果（酸が保たれた、熟度、凝縮感）
- **③ ほかの年との位置づけ（任意・1文）**

### 語り口

- 主語は「生育」「成熟」「ブドウ」
- 前の文が次の文の原因になる順接の流れ。意外な結果を示す逆接はよいが、言い換えだけの逆接で流れを切らない
- 常体（だ・である）。事実に沿って簡潔に。詩的な飾りは要らない
- 気象サマリーの数値を繰り返さない。紹介文の「です・ます」や体験の描写を混ぜない。欄に無いことを作らない
