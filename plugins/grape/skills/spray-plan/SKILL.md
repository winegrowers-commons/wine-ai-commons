# 防除の計画と記録の点検

## 本家

- 名前：skills-for-agriculture の `s4ag-pests`（Finn Fitzsimons、MIT ライセンス）
- 原文：https://github.com/human-avatar/skills-for-agriculture/blob/main/skills/s4ag-pests/SKILL.md
- 中身：総合的病害虫管理（IPM）のはしご。見分ける → 被害の水準を見る → 耕種的な対策 → 生物的な対策 → 有機の資材 → 化学農薬、と低い段から上がる。各段で前提（害虫・作物・急ぎかどうか・有機か慣行か）を確かめてから進む

## 本家の読み方

1. `skills-for-agriculture:s4ag-pests` が入っていれば、それを呼んで手順に従う
2. 入っていなければ、上の原文を開いて読み、その手順に従う（毎回読むので、本家が更新されれば新しい版が使われる）
3. 原文が開けなければ、その旨を伝えて止まる。下の調整だけで進めない

本家が話す薬剤名・用量は海外の登録に基づく。**日本で使ってよいかは、必ず下の調整で確かめ直す。**

## 0. 設定を読む

🧭 AI設定ページから、接続表の `spray_records`（防除歴）、`materials`（資材）、`fields`／`blocks`（圃場・区画）、`plantings`（植栽）と、自分ルールのこのスキルの欄（有機か慣行か、使う都道府県の防除ガイド、出荷先の要件など）を読む。

## 調整（本家と違うところだけ）

### 1. 日本の農薬取締法の使用基準を最優先にする

薬剤を提案・点検するときは、**農薬登録情報提供システム**（農林水産省・FAMIC）で、使う日の時点の登録を確かめる。記憶や本家の記述で決めない。確かめるのは次の全部。

- 適用作物に「ぶどう」があるか（「小粒種ぶどう」「大粒種ぶどう」など区分があれば、その品種がどれに入るか）
- 適用病害虫
- 希釈倍数か使用量、散布液量
- **使用時期**（収穫前日数）
- **本剤の使用回数**と、**有効成分ごとの総使用回数**（同じ成分を含む別の剤も合わせて数える）
- 使用方法

確かめられなかった剤は「国内での可否は未確認」と書き、提案に入れない。登録は変わる（失効・適用拡大）ので、前年の暦をそのまま使わない。

### 2. 耐性を避ける系統のローテーション

殺菌剤は FRAC コード、殺虫剤は IRAC コードで系統を確かめ、同じ系統を続けない。系統ごとの年間の使用回数の目安は、都道府県の防除ガイドに従う。

### 3. ワイン用ブドウで先に考える病害

日本の多湿な夏で主に問題になるのは、べと病、灰色かび病、晩腐病、黒とう病、うどんこ病、褐斑病。見立てと防除の時期は、暦の日付ではなく生育ステージ（E-L、BBCH）と降雨で考える。病害の予測ツールや気象データが接続表にあれば使う。

都道府県の病害虫防除所の発生予察情報と、防除ガイド（例：北海道なら「北海道農作物病害虫・雑草防除ガイド」）を、本家の一般論より優先する。

### 4. 醸造への影響も見る

- 収穫に近い硫黄剤は、発酵中の還元臭（硫化水素）の原因になりうる
- 銅剤は、ワインの銅の残りや酵母への影響に注意する
- 収穫前日数に加えて、醸造先（自社・委託先・買い手）の受け入れ条件があれば、自分ルールに従う

これらは一般的な注意。具体的な日数や濃度を出すときは、research の science-research の基準で資料を確かめる。

### 5. 記録の点検

`spray_records` の各行について確かめる：日付／圃場・区画／剤名と有効成分／FRAC・IRACコード／希釈倍数か使用量／散布液量／対象の病害虫／作業者／天気。そのうえで、

- 使用回数と、有効成分ごとの総使用回数が上限を超えていないか（シーズンの頭から数える）
- 最後の散布から収穫予定日まで、収穫前日数を満たしているか
- 同じ系統が続いていないか
- 適用作物・希釈倍数が登録と合っているか

違反のおそれは🔴、確かめられないものは🟡で示す。記録の書き換えはしない。直し方を出し、利用者が直す。

### 6. 出し方

防除暦や今週の提案は、表で：日付（か生育ステージ）／対象／剤（有効成分・FRAC）／希釈倍数／使用時期と回数の残り／根拠（登録の確認日、防除ガイドの該当ページ）。
