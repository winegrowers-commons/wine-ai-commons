# 制度カタログ

補助金・助成金の制度ごとに1枚、`catalog/<制度のID>.md` を置く。生産者どうしで共有する知識で、事業データ（申請した会社名・金額・提出書類）は入れない。

使う前には必ず公式の公募要領で最新を確かめる。カタログと違えば、直す提案を出す。

## 1枚の形

```markdown
# 制度の名前（年度）

- 所管：
- 公式ページ：（URL）
- 確認日：YYYY-MM-DD

## 対象
## 主な要件
## 補助率・上限
## 対象になる経費・ならない経費
## 併用の可否
## 締切の傾向
## 交付後の義務（実績報告、処分制限の期間など）
## 申請でつまずいた点（生産者の声）
## 審査で効いたこと（生産者の声）
```
