# 理事会の議事録

打合せのメモから、法令・定款の記載事項を漏れなく満たした理事会の議事録を作る。書式と言い回しは、その団体の過去の議事録にそろえる。

## 0. 設定を読む

🧭 AI設定ページから、このスキルの欄を読む。無い項目は利用者に聞く（推測で書かない）。

| 設定 | 中身の例 |
| --- | --- |
| 団体の正式名称 | 一般社団法人〇〇協会 |
| 定款の関連条文 | 理事・監事の人数、理事会の構成、招集の省略、議長、決議の方法、報告の省略、議事録の署名、事業年度 |
| 代表理事・理事・監事の氏名 | 記名欄に使う |
| 議事録作成者 | 通常の担当者 |
| 議事録の置き場 | 接続表の `meetings`（会議・議事録） |
| 過去の議事録 | 書式とトーンの手本 |

## 1. 法令の根拠（一般社団法人及び一般財団法人に関する法律）

- **第91条第2項**：代表理事は3か月に1回以上、職務の執行状況を理事会に報告する（定款で「4か月を超える間隔で年2回以上」とした場合はその間隔）
- **第95条第3項**：出席した理事と監事が議事録に署名か記名押印する
- **第97条**：理事会の日から10年間、主たる事務所に備え置く
- **第98条第2項**：職務執行状況の報告は、書面による報告の省略ができない（理事会で実際に報告が要る）

**施行規則 第15条第3項（記載事項）**

1. 開催の日時と場所（テレビ会議などで出席した人がいればその方法も）
2. 招集権者以外が招集したときはその旨
3. 議事の経過の要領とその結果
4. 決議に特別の利害関係を持つ理事がいればその氏名
5. 競業・利益相反取引の報告、監事の報告・意見があればその概要
6. 定款で議事録署名人を定めているときは、代表理事以外の出席理事の氏名
7. 出席した会計監査人の氏名か名称
8. 議長がいるときはその氏名

条文番号は、使う前に e-Gov法令検索で今の条文を確かめる。

## 2. 構成（この順で全部入れる）

```
# 開催要領
日　時：令和●年●月●日　●：●～
場　所：（オンライン開催、または場所の名前）
出席状況：
理事：総理事●名中 本人出席●名（氏名）
監事：総監事●名中 本人出席●名（氏名。0名なら氏名は省く）

# 議長選任の経過
（決まった文。開会の宣言 → 成立の確認 → 議長の選任 → 議事録作成者の指名）

# 議案審議
## 第●号議案　●●の件
（提案の内容 → 採決の結果）

## 代表理事 職務執行状況報告
（法第91条第2項による報告。対象の期間を書く）

## 報告事項
（番号付きで）

# 閉会
（決まった文 → 議事録作成の根拠 → 日付 → 記名欄）
```

## 3. 議題の分け方

- **決議事項（第●号議案）**：承認・可決が要るもの。入会の承認、支出の承認、規則の制定、人事、名称の使用の承認など
- **代表理事 職務執行状況報告**：前回の報告期間の翌月から、今回の理事会の前月までが対象。前回から3か月を超えていれば必ず入れる。前回の期間と重ねない
- **報告事項**：決議の要らない共有、進み具合、今後の予定

## 4. 職務執行状況報告の確認

1. 前回の議事録で報告した期間の終わりの月を確かめる
2. 今回の理事会の前月を、今回の終わりの月にする
3. 前回の終わりの翌月を、今回の始まりの月にする
4. 前回から3か月以内なら省いてよい。超えていれば必須
5. 事業年度の始めから数えて、報告されていない空白の期間が無いか確かめる

## 5. 言い回し

- 議案の始まり：「表記の議題について、●●から説明があった。」
- 採決：「議長が賛否を議場に諮ったところ、出席理事●名の満場一致をもって異議なく可決した。」（または「承認した。」）。反対・保留があれば「賛成●名、反対●名をもって可決した。」
- 報告：「●●である旨の報告があった。」「●●する旨、●●から報告があった。」
- 敬称は付けない。外部の個人には「氏」を付ける。団体名は正式名称

**議長選任の決まった文**

```
定刻●時に代表理事 〈氏名〉が開会を宣し、本日の理事会は定款所定数を満たしたので有効に成立した旨を告げた。続いて議長の選任を諮ったところ、満場一致を持って代表理事 〈氏名〉が議長に選任された。
議長より挨拶の後、議事録作成者を指名したい旨を述べたところ、異議なく賛成があったので、議長は、次の者を議事録作成者に指名した。
議事録作成者　〈氏名〉
```

**閉会の決まった文**

```
以上をもって議案全部の審議を終了したので、議長は閉会を宣した。
上記の議案を明確にするため、議事録作成者が議事録を作成し、出席した理事及び監事が次に署名又は記名押印する（定款第〈条〉・法人法第95条3項）。

令和●年●月●日
〈団体の正式名称〉

議長　代表理事　〈氏名〉
理事　〈氏名〉
（監事が出席していれば）監事　〈氏名〉

議事録作成者　〈氏名〉
```

記名欄には出席した理事・監事だけを書く。欠席者は入れない。㊞は付けない（署名・押印は印刷後）。

## 6. 記載事項のチェック（作ったあと全部）

- [ ] 開催の日時
- [ ] 開催の場所（オンラインならその旨）
- [ ] 出席理事の氏名と人数
- [ ] 監事の出席状況
- [ ] 議長の氏名
- [ ] 議事録作成者の指名
- [ ] 各議案の経過の要領と結果（採決）
- [ ] 特別の利害関係を持つ理事（いれば）
- [ ] 職務執行状況報告の要否と、要るなら対象期間
- [ ] 出席した理事と監事の記名欄
- [ ] 根拠（定款の条・法人法第95条3項）の引用
- [ ] 記名欄に㊞が無い

## 出力

Notion の Markdown。`meetings` のページにそのまま貼れる形。メモに無い発言や数字は作らず、分からない箇所は「●」のまま残して最後に一覧で聞く。
