# 機械の整備項目と部品の登録

1台の機械について、**取扱説明書に書いてあることだけを根拠に**、整備項目と必要な部品を登録する。

## 絶対のルール

- **取説に書いていない項目は登録しない。**「一般的な乗用モアならこう」という機種をまたいだ推測はしない。よくある項目（バッテリ、タイヤの空気圧、ベルトなど）でも、その機械の取説に無ければ入れない
- 取説のPDFを全ページ読めないときは、該当する章の文字を利用者に頼み、**中身を確実に読めるまで案を作らない**
- 各項目と部品のメモに、**取説の章・表番号・ページ**を必ず残す
- 分からない値は「取説に記載なし」と書いて空にする。ネットの推測で埋めない（ネットで補ったものはメモにそう書く）

## 0. 設定を読む

🧭 AI設定ページの接続表から `equipment`（機器）、`maintenance_logs`（整備・保守）、`parts`（部品）を読む。無ければ止まって伝える。プロパティ名が下と違うときは接続表の対応に従う。

## 1. 材料を集める

- 対象の機械のページ（本文・備考・メモ）
- 取扱説明書のPDFの**全ページ**
- リンクしている機械の解説ページがあれば本文も
- 既存の整備項目（その機械に紐づくもの）と、同じ品番・同じオイル規格の部品が無いか。あれば新しく作らず、リレーションの追加と差分の更新だけにする

優先して読む章：定期点検表・保守点検表／オイル・グリースの規格表／消耗部品の一覧・部品番号表／長期保管・シーズンオフの処置／安全装置の作動点検／仕様表（オイル容量・タンク容量など）

## 2. 整備項目を抜き出す

**タイトル**：整備項目の名前だけ。機械名・型番は入れない（「対象機械」のリレーションで分かるため）。例：`エンジンオイル＋フィルタ交換`、`エアクリーナー清掃`

**重要度**

| 重要度 | 基準 | 例 |
| --- | --- | --- |
| 最重要 | 怠ると人身事故・火災・重大故障に直結。ブレーキ、燃料系、回転刃、排気まわりの可燃物、安全カバー | 駐車ブレーキの効き、燃料パイプの定期交換、刃の点検、排気管まわりの草くず除去 |
| 重要 | 怠るとエンジン・駆動系の寿命を数年単位で縮め、修理費が大きい | エンジンオイル交換、エアクリーナー清掃、冷却フィン清掃、ミッション・HSTオイル点検 |
| 推奨 | 始動性・操作性に影響。放置すると性能が落ちる | 点火プラグ、燃料フィルタ、タイヤ空気圧、ベルト・ワイヤの張り、安全スイッチの作動 |
| 任意 | 年1回まとめてで足りる | 各部のグリス注油、バッテリ補水、長期保管処置 |

**担当**：取説で販売店を指定している、エア抜きを伴う油の交換（HSTなど）、燃料系の分解、分解後に精密な調整が要る、失敗すると修理費が数十万円になる → **販売店に依頼**。それ以外の点検・清掃・量の確認・簡単な交換・調整・注油 → **自分**。境目のものは確認のときに示して判断してもらう。

**整備の間隔**：「整備間隔」（年数の数値）と「整備期間（詳細）」（取説の指示をそのまま）の両方を入れる。

| 取説の指示 | 整備間隔 | 整備期間（詳細） |
| --- | --- | --- |
| 年1回 | 1 | 年1回 |
| 3年ごと | 3 | 3年ごと |
| 100時間ごと／年1回 | 1 | 100時間ごとまたは年1回（早い方） |
| 初回50時間 | 空 | 初回運転50時間で1回のみ |
| 使用前・使用後 | 空 | 使用前点検／使用後点検 |

詳細は取説の言い回しを優先し、まとめない。書いていなければ空にする。

**メモ**：①根拠（取説の章・表・ページ）②規格や数値（オイル容量、粘度、寒冷地向けなど）③時間の基準・きっかけがあれば原文 ④注意点・怠ったときの影響（重要度の根拠）

## 3. 部品を抜き出す

**対象**：規格品番が分かるもの（オイル・フィルタ・プラグ・刃・ホース）／定期交換する消耗品／汎用品でも規格指定のあるもの（API GL-4 #90 など）／**取説の消耗品・部品番号表にあるもの**（今は対応する整備項目が無くても登録する。関連整備項目は空でよい）／**取説に品番のある特殊工具**（名前に「（工具）」を付ける）

**名前**：一般名＋特徴的な規格。規格が違えば別のレコード。例：`エンジンオイル 10W-30 API SJ以上`、`ミッションオイル API GL-4 #90`

**共用の部品**：オイル・フィルタ・プラグなどは、先に部品DBを名前で探し、あれば新しく作らずリレーションを足す。

| プロパティ | 書くこと |
| --- | --- |
| 部品名 | 一般名＋規格。互換品があれば代表を1つにし、ほかは注意点へ |
| コード | メーカー純正品番。統合された旧品番があれば両方 |
| 購入先 | 販売店名かURL（取説の販売店、通販の実際のURL、メーカー直販など） |
| 注意点 | 互換の制約（GL-5不可など）、寒冷地向け、添加剤の可否、一緒に替える部品、ロットによる違い |
| 関連整備項目 | この部品を使う整備項目を全部 |

## 4. 登録の前に見せる（承認を取る）

2つの表を見せる。

- 整備項目の案：タイトル／重要度／担当／整備間隔／整備期間（詳細）／必要な部品／メモの要旨
- 部品の案：部品名／コード／購入先／注意点／関連整備項目

一緒に書く確認事項：取説に見当たらなかった項目／重要度で迷った項目／担当で迷った項目／既存と重なる部品（リレーションの追加でよいか）／時間・使用前後が基準で整備間隔を空にした項目／今は整備項目の無い消耗品・特殊工具

## 5. 登録する

- **部品 → 整備項目** の順で作る（整備項目から部品にリレーションを張るため）
- 終わったら確かめる：その機械の整備項目が全部見えるか／部品のリレーションが想定どおりか／部品側にも双方向で反映されているか／タイトルに機械名・型番が混ざっていないか／整備期間（詳細）に取説の原文が入っているか
- 報告：登録した整備項目の数（重要度別）、部品の数（新規／既存へのリレーション追加）、登録しなかった項目とその理由
