# 醸造・栽培で間違えやすいパターン

技術的な記述を、AIが繰り返し間違えるパターンに機械的に当てて、見落としを防ぐ。fact-check の❌候補チェックリストに足して使う。単独でも使える。

最初に research の verification-basics を読み、規律と出力の形に従う。指摘にはパターンIDを付ける。science-research の「間違えやすいパターン」の1〜16はこの一覧と同じ。片方を直したら、もう片方も合わせる。

## 優先して当たる資料

| 種類 | 資料 |
| --- | --- |
| 公的 | AWRI、OIV、国税庁（添加物の一覧）、酒類総合研究所、大学のエクステンション（Cornell、UC Davis など） |
| 実務 | メーカー公式のプロトコル・技術資料（Lallemand、Laffort、Scott Labs、Enartis など） |
| 学術 | 査読付きの論文・総説（OENO One、FEMS Yeast Research など） |

用量・比率・手順の数値は、メーカー公式の資料と逐語で照らす。

## パターン一覧

| ID | パターン | 見つける手がかり | 確かめ方 | 例 |
| --- | --- | --- | --- | --- |
| P01 | 推奨の向きの逆転 | 「避ける」「推奨」「向く」 | 公式資料の推奨条件と向きを照らす | 高アルコールでは同時接種を避ける（実際は有効） |
| P02 | 分析法の能力の過大評価 | 「正確」「〜でのみ」「確認できる」 | 検出下限と判定基準を並べる | ペーパークロマトで正確に終了判定（下限は約100 mg/L） |
| P03 | 定義の構成要素の偏り | 「主に」「〜とは」 | 構成要素を全部挙げた定義と照らす | YAN＝主にアンモニア態窒素 |
| P04 | 官能の記述と化合物の取り違え | 匂いの表現＋化合物名 | 化合物ごとの記述をS2で照らす | メルカプタン＝タマネギ臭 |
| P05 | プロトコルの比率・用量のずれ | g/hL、比率、手順番号 | メーカー公式と逐語で照らす | スターターは停滞ワインの1/3量 |
| P06 | 絶対表現 | ほぼない／唯一／最大／完全／必ず | 弱める前提で裏付けを探す | 接種した発酵に誘導期はほぼない |
| P07 | 出典不明の細かい数値・母数の取り違え | 1/N、N倍、細かい小数 | 母数（粒数か菌数か）を確かめる | ある酵母は全体の1/5000未満 |
| P08 | 旧学名 | 属名・種名 | 今の学名を確かめる | Kloeckera apiculata |
| P09 | 機序の創作 | 「〜が選択的に作用」「〜が引き金」 | 総説に同じ機序があるか | アセトアルデヒドの選択毒性 |
| P10 | 介入の時期の誤り | 「初期に」「〜の時点で添加」 | 糖の消費の割合・段階で示された公式の推奨時期と照らす | DAPを定常期に添加 |
| P11 | 節どうしの推奨の衝突 | 同じ操作への複数の言及 | 同じ操作の推奨をページ全体から集めて並べる | 表では順次接種、トグルでは同時接種を推奨 |
| P12 | 閾値の境界のずれ | pH・温度・濃度の境界 | 好適・不適の範囲の両端と照らす | MLFはpH3.2以上（AWRIは3.3〜3.5が好適、3.1未満は不適） |
| P13 | 標準的な対策の抜け | 対策の一覧 | 公式資料の対策一覧との差 | 還元臭の対策に銅が無い |
| P14 | 単位の表記・国内で使えるか | 単位、添加物名 | 正式な単位表記、国税庁の添加物の一覧 | Kcal、DAPの国内での使用可否 |
| P15 | 物質の形態・基準が無い | SO2・糖・アルコールの濃度 | 遊離／総／分子状、潜在／実アルコールなどの基準 | 乳酸菌は10 mg/Lの亜硫酸でも死ぬ |
| P16 | 数学的な性質の転用 | 指数関数的、比例、変曲点 | その性質がどの量（菌数か糖濃度か）のものか | 対数増殖期はBrixが指数関数的に下がる |

## 手順

1. 対象を読み、fact-check の1の方法で atomic claim を全件書き出す
2. 各主張を手がかりの語で走査し、当たるパターンIDを付ける
3. P11は操作（接種、添加、加温など）ごとに主張をまとめ、ページ全体で照らす
4. 当たった主張は優先資料で照らす
5. 修正案にもP01〜P16を当てる。製品の用量は「製品名＋用量」で書き、一般値として書かない
6. verification-basics の形で🔴🟠🟡を付けて報告する。各指摘にパターンIDを付ける

## 繰り返し点検するとき

- 2回目からは、前回✅で本文が変わっていない主張は外す
- 直した箇所と、前回🟡だった主張は見直す
- 新しい🔴🟠が0件になったら終える
- どのパターンにも当たらない誤りを見つけたら、新しいパターンの候補として付録に書き、propose-change で提案する

## しないこと

- パターンに当たらない主張を無条件に✅にする
- メーカー資料を読まずに用量の数値を通す
- 修正案に出典の無い数値を入れる
