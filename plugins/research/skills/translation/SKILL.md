# 外国語資料の日本語化

原文の情報を落とさず日本語で読めるようにし、現場ですぐ引ける形に整える。OCRの崩れや不明点は隠さずに示す。

## 入力

PDF（原文かOCRの文字）、WebページのURLか本文、画像の中の文字。任意で、対象の機器・製品名と型番、メーカー・発行者と連絡先、発行年月とページ数、想定の読み手。

## 1. 原文に忠実に

- **数値・型番・規格名・法令名・有効成分名・単位は原文のまま。** 勝手に換算・省略・丸めをしない
- インチ（1"、¾"、½" など）は mm にしない（配管・ボルトの規格で部品を買えなくなるため）
- **安全の語（Danger、Warning、Caution、Verboten、Achtung など）は義務の形で訳す。**「〜してください」ではなく「〜しなければならない」「〜してはならない」
- 固有名詞（メーカー名、地名、法令の略称など）は原つづりのまま。要れば日本語の解説を別のブロックで添える
- 自信の無い訳は断定せず、原文を併記する（例：「流量調整バルブ（Stromregelventil）」）

## 2. 読みやすい日本語

- 業界の外で通じにくい熟語・難読漢字・古い字面の語は、ふつうに分かる言い方に換える。1と食い違うときだけ原語を残し、初出に括弧で平易な説明を添える
- 例：「嵌合」→「しっかりはめ込む」、「螺着」→「ねじ止め」、「油浴式」→「オイル浴式（ギア全体がオイルに浸かって潤滑される方式）」、「涵養」「惹起」などの硬い語 → ふつうの言い回し
- JIS・法令・業界標準で公式に使われる専門用語は残してよい（初出に説明を添える）
- OCRの誤りやタイプミスと見分けにくい難読語は特に避ける

## 3. 構造

- 原本の章立て・節番号を保つ。見出しは「`# 1）はじめに`」のように原文の番号＋日本語
- 章の間は区切り線で分ける。冒頭に目次を置く
- 図表は原本の図番号（図1、Tabelle 2 など）を保ち、キャプションに原文名を斜体で残す

## 4. 装飾の意味をそろえる（Notion の callout）

| 用途 | 印と色 | 使う場面 |
| --- | --- | --- |
| 危険・絶対禁止 | 🔴 🚨／赤 | 人身事故、法令違反、保証が切れる |
| 警告・重要な注意 | ⚠️ ⚡／オレンジ | 機器の損傷、運転条件の逸脱 |
| 注意・確認 | 🟡／黄 | 戻し忘れ、設定の確認 |
| 参考・技術データ | ℹ️ 📐 🧮／青 | 残量値、計算例、仕様 |
| 解説・読み替え | 💡 📚／灰 | 背景知識、日本での読み替え |
| 環境 | 🌱／緑 | 環境保護、水系の保護 |
| 法令・契約 | ⚖️／灰か赤 | 保証条項、約款 |
| 原本の情報 | 🏷️／灰 | 対象機種・発行日・連絡先 |
| 国内での読み替え | 🇯🇵／青 | 日本で手に入る代わりの品・相当する規格 |

箇条書きの中の優先度には 🔴🟠🟡、✅⚠️❌ を使う。規格値・寸法などの一覧は表にする。数式は `$$〜$$` か `$〜$`（前後に空白）。

## 5. 解説を足してよいとき

- 読み替えが要る（例：ドイツの法令 → 日本の道路交通法・農機の規定）
- 業界の慣習・専門用語の説明が理解を助ける
- 国内で手に入る代わりの品がある（グリースの銘柄、工業用油、部品など）

足す解説は必ず callout か「💡 解説」の引用ブロックにして、原文と見た目で区別する。

## 6. 冒頭と末尾の決まった形

冒頭に3つの callout と目次：

1. 原本PDF（添付）
2. 🏷️ 対象、メーカー・発行者（正式名と所在地）、連絡先、発行（年月日、ページ数）
3. ❗ このページの位置づけ：OCRの文字をもとに作った／数値・型番・規格名・安全の語は原文のまま／OCRで数値が崩れやすい表は原本を見ること／不明点は末尾の一覧にある／法令・機関名は原つづりのままで、日本の制度へ自動では読み替えない

末尾に：

- **不明点・要確認の一覧**（表：箇所／問題の種類／原文の引用／対応）。問題の種類は「OCR崩れ」「表記ゆれ」「本文の欠落」「型番の相違」「原文に記載なし」「契約文（全訳省略）」
- **関連資料**：原本の入手先、公式サイト・データシート、関連する国内の規格・代わりの資料

## 7. 手順

1. 原文の情報（タイトル、発行者、発行日、ページ数、言語）を確かめる
2. 章立てを抜き出し、原本の番号を保った見出しの木を作る
3. 冒頭の3つと目次を置く
4. 章ごとに順に訳す（1〜2のルール）
5. 図表はキャプション付きで置く。OCRの信頼性が低い数値の表は「原本を必ず見る」callout に置き換える
6. 読み替え・背景の解説が要る箇所に 💡 か 🇯🇵 を入れる
7. 末尾の2つを置く
8. 全体を読み直し、装飾の色と印が4の表に従っているかを確かめる

## しないこと

- 意訳で膨らませる、原文に無い数値・事実を足す（要るなら解説の中に出典付きで）
- 章の並べ替え
- 法令・規格・契約の条項を要約で置き換える（要点を抜くときは原文への参照を残す）
- 安全の語を丁寧語に弱める

## 出力

Notion の Markdown だけ。前置き・後書きを付けず、そのまま貼れる形で。「章ごとに分けて」と言われたら章ごとに出す。「要約版」と言われたときだけ要約に切り替え、その旨を最上部の callout に書く。原本・図・数値表が足りなければ、欠けたまま進めず不明点の一覧に挙げてから続ける。
