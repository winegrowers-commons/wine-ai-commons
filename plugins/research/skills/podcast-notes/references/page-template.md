# 解説ページの型

`podcast_episodes` の行のページ本文に、この順で書く。書き方の土台は core の writing-for-humans。読み手は「その分野に詳しい高校生」：パッと読んで要点が分かり、詳細はトグルで追える。

1. **この回の核心**：黄色のコールアウトに2〜3文。何が言われた回で、何がいちばん新しい・大事か
2. **全体像**：論点どうしの関係を図にする（diagram スキルで、Mermaid か NotionのHTMLブロックを選ぶ）。図の下に、出演者・話の土台（本・研究・事件など）・話し手の立場を箇条書きで3行ほど
3. **論点ごとの解説**：論点1つにh3のトグル1つ。見出しに時刻（mm:ss〜mm:ss）を入れ、音声で確かめられるようにする。依頼者が特に知りたいテーマがあれば、その見出しに★を付けて厚く書く
4. **補足（番組外の情報）**：自分で足した背景・出典は、ここに分けて「（読み）」「（要確認）」を付ける。話し手の発言と混ぜない
5. **自分ごとにするための問い**：その人の仕事（🧭 AI設定ページの事業内容）に、無理なく引きつけた問いを2〜3個。結びつかなければ書かない
6. **用語ミニ辞典**：表で、用語と一言の説明
7. **文字起こしの誤変換メモ**：トグル。概要欄・人名・書名と照らして直したもの。推測は（推定）と書く
8. **元データ**：文字起こし・エピソード・概要欄の参考リンクと、「自動文字起こしをもとにClaudeがまとめたもの。細部は音声で確認を」の注記

守ること

- 英語など外国語の回でも、解説は日本語で書く。用語は原語を（ ）で添える
- 長い引用はしない（1か所15語未満、1回につき1か所まで）。自分の言葉で言い換える
- 話し手の主張を、事実として断定しない。「〜と話していた」「〜という立場」と書く
