# 参考文献ページの点検

既存の文献ページを点検し、ページごとにギャップ・修正案・原文を取り直す必要・登録ログに足す文を出す。書き換えない。直すのは利用者の承認後に reference-registration（作り直し）か page-review（削除など）に渡す。

最初に research の verification-basics を読み、規律と出力の形に従う。書誌のルールはその `references/bibliography.md`。

## 入力

- ページ1件、URLを並べたもの（1回5件まで）、またはDB全件（5件ずつ自動で区切り、承認を挟まず続ける）
- 任意：点検するカテゴリを絞る、作り直しの対象を先に決める

## 1. 読み込みとモードの判定

各ページのプロパティ（書籍名・形態・発行年・URL・要約・著者・引用ページ・添付）と本文（要約・構造化ノート・注釈・登録ログ）を読む。

- **軽量モード**：末尾に「登録ログ」があるページ。プロパティの完全さと登録ログのつながりだけを見る。原文との照合はしない
- **重点モード**：登録ログが無いページ。下の8カテゴリ全部と、原文の取り直し、引用アンカーと数値の3点セットの逐一の確認

判定は登録ログの有無だけで行う。スキルの版は見ない。

## 2. 8カテゴリの点検

| カテゴリ | 確かめること | 不適合 | 軽量 | 重点 |
| --- | --- | --- | --- | --- |
| プロパティの完全さ | 書誌の必須項目が埋まり、bibliography.md に合っているか | 🔴 空欄・誤り | ✓ | ✓ |
| 原文が取れるか | DOI・URLが開けるか、PDFか代わりのURLがあるか | 🔴 取れない | — | ✓ |
| 原典だけで書かれているか | 本文と要約に原典外の情報（文脈・示唆）が混ざっていないか | 🟠 混入 | — | ✓ |
| 引用アンカー | 要約・ノートの主張にアンカーがあるか | 🟠 欠け | — | ✓ |
| 数値の3点セット | 値＋単位＋原文の場所になっているか | 🟠 形式の不備 | — | ✓ |
| 構造化ノートの構成 | 論文／Web／本のテンプレートに沿っているか | 🟠 構成のずれ | — | ✓ |
| 信頼度の印 | 🟡🔴だけに付いているか（🟢の乱用が無いか） | 🟡 不統一 | — | ✓ |
| 登録ログのつながり | 日付・種別・版が時系列で整っているか | 🟡 不整合 | ✓ | ✓ |

**原文の無いWeb系は削除候補に固定**：形態が学術誌・Webページ・Blog・雑誌・その他で原文が取れないページは、ほかの結果によらず総合判定を「🔴 削除推奨」にする。

**総合判定**：🔴が1つ以上、🟠が4つ以上、または削除推奨 → 🔴 大きく直す／🟠が1〜3つ、または🟡が3つ以上 → 🟠 一部を直す／それ以外 → 🟢 準拠

**重複**：タイトルかDOIが完全一致するページは重複として、統合案を出す（自動では統合しない）。似たタイトルは疑いとして示すだけ。

原文が40ページを超える文献は1件ずつ点検する。

## 3. ページごとの記録

```
--- 点検結果: 文献タイトル ---
モード: 軽量 / 重点
総合判定: 🔴 / 🟠 / 🟢 / 🔴 削除推奨
ギャップ:
• [🔴] プロパティ：空欄 = 発行年、著者
• [🟠] 引用アンカー：要約の3主張中、アンカーあり1件
修正案: （少なければ before/after。多ければ作り直しをすすめる）
原文の取り直し: 取れる＆小さい直し／取れる＆大きい直し（登録へ渡す情報を整える）／取れない＆本など（原文を求める文）／取れない＆Web系（削除をすすめる）
登録ログに足す文: - YYYY-MM-DD 点検：最新の基準で点検 / 要修正=〇〇 / 状態=修正保留
```

## 4. まとめのレポート（全部終わってから1枚）

1. 要約：`点検 N 件：🔴X / 🟠Y / 🟢Z`、重複、原文が取れない件数、削除推奨の件数、モードの内訳
2. 🔴と🟠を1件ずつ、5択で聞く：「修正案を適用」「作り直しを reference-registration に渡す」「削除（DBと引用先の両方から）」「スキップ（保留）」「却下（現状維持）」
3. 🟢は件数と1行。一覧は折りたたみ
4. 折りたたみ：重複の組と統合案／原文が取れないページ（本など・Web系の別）／点検の限界／登録ログに足す文の一覧／プロパティの更新案（点検の状態・最終点検日など）

## 5. 承認のあと

書き換えはしない。選ばれた結果に合わせて、渡す情報を整えて出す。

- 修正案を適用：ページと before/after の一覧
- 作り直し：ページと原文のURL・PDFの情報を reference-registration 向けに
- 削除：ページと引用先のページの一覧を page-review 向けに
- スキップ・却下：記録だけ

## しないこと

- 書き換え・自動の統合・勝手な作り直し
- 原文を取らずに数値やアンカーが正しいと断定する
- 軽量モードで原文やアンカーを点検する
- 原文の無いWeb系を🟠以下で済ませる
- DBのプロパティ（点検の状態など）を書き込む。案を出すだけ
