# 参考文献の登録

文献1件を `references` に登録する。書誌の値（プロパティ）、ページ本文（AI要約）、登録ログの3つを作り、原典と照らして検証してから書き込む。細かい項目と書式は `references/spec.md`、書誌の正規化は research の verification-basics にある `references/bibliography.md` に従う。

## 0. 設定を読む

🧭 AI設定ページの接続表から `references`（参考文献DB）を読む。知識コモンズの参考文献に入れるか、自社のDBに入れるかは接続表で決まる。無ければ止まって「参考文献DBが未接続です」と伝える。

## 1. いちばん大事な3つ

1. **原典だけから書く**：ページ本文・「要約」・書誌の値は、渡された原典（PDF・URL・抜粋）に書いてあることだけで作る。呼び出し元のページ、チャットのやり取り、ワークスペースのほかの情報、AIの一般知識を混ぜない
2. **原典に無いことは「備考」に分ける**：登録したときの文脈、利用者の観点、自社の仕事への示唆、関連ページへの橋渡し、重複の疑いなどは、すべて「備考」プロパティに書く。本文と「要約」には入れない
3. **原文が取れなければ登録しない（形態による）**：学術誌・Webページ・Blog・雑誌・その他は、原文が取れなければ登録をやめ、削除をすすめて報告する。書籍・調査報告書・セミナーだけは、利用者の了承があれば書誌だけを登録できる（紹介文を引用し、AI要約は作らない）。書誌だけの登録に自動で切り替えない

## 2. 流れ

1. **処理の前の確認**：bibliography.md の8（URLが開けるか・タイトル・DOI・撤回・重複）。1つでも問題があれば止めて報告する。重複していれば新規登録せず、既存ページへの「引用ページ」の追加を提案する
2. **原文を取る**：直接取れなければ、オープンアクセス版、機関リポジトリ、プレプリント（arXiv、bioRxiv、HALなど）、著者の公開版を探す。それでも無ければ1の3に従う
3. **確認する**：入力の種類の認識、特に見てほしい観点、呼び出し元以外に「引用ページ」へ足したいページ。書誌だけの登録になる場合は、ここで了承を取る
4. **書誌の値を作る**（spec.md の「パート1」）
5. **ページ本文を作る**（spec.md の「パート2」）：要約（800字が目安、段落に分ける）、構造化ノート（論文／Web記事／本でテンプレートを変える）、注釈
6. **検証する**（spec.md の「検証」）：書誌の照合、数値と固有名詞の転記、翻訳と解釈、整合性。❌が1つでもあれば直して最初からやり直す。全部✅になってから書き込む
7. **書き込む**：ページのアイコンは赤い本（Notion の `icons/book-closed_red`）に固定する。APIやMCPで作るときもアイコンを指定する
8. **登録ログを足す**（spec.md の「パート3」）：ページ末尾、トグルの外。過去の行は消さない

## 3. 書き方の要点

- **引用アンカー**：原文由来の主張には該当箇所を付ける。`〔p.425〕〔Table 2〕〔Fig.3〕〔Abstract〕`、Web記事は見出し名。同じ節の主張はまとめて最後に1回だけ付ける。「同上」「ibid.」は使わない。アンカーを付けられない主張は書かない
- **数値は3点セット**：値＋単位＋原文の場所。単位を換算したら元の値も書く（例：`平均30 kg/10a（原文：3000 kg/ha）〔Results節〕`）
- **分かりやすさを優先した翻訳**：不自然な直訳より、自然な意訳か原語のまま。業界で原語のまま通じる語（must、lag、pumpover など）は訳さない。専門用語は初出だけ「日本語（原語）」と併記する。固有名詞・品種名・機関名は原語のまま
- **信頼度の印**：原文に書いてあることには付けない。推論したことにだけ 🟡、不明・取れない・原文と矛盾しそうなことにだけ 🔴
- **AIの系統的検索レポート**（Elicit、Gemini Deep Research）は特別な扱いがある。spec.md の「AIレポートの扱い」に従う

## 4. 複数をまとめて登録するとき

- 1件ずつ「書誌の値＋本文」を1組にして、`--- ソース n/N: 短いタイトル ---` で区切る
- 要約の調子・細かさ・字数をそろえる。訳語は最初の1件で決めて、あとも同じにする
- 全件にアイコンが付いているか、登録後に確かめる

## 5. 終わりに

登録したページへのリンクと、検証結果の要約（`Step1〜4 ✅`）を1行で返す。備考に書いたことがあれば一言添える。
