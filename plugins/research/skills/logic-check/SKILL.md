# 論理の整合チェック

ページの**内側**の整合だけを見る。外の資料との照合は citation-check と fact-check、表現・構成のわかりにくさは core の writing-for-humans と structure-reading の担当。

最初に research の verification-basics を読み、規律と出力の形に従う。ID は `LC-001` から。

## 原則

1. 根拠はページの中の記述どうしの関係だけ。外の知識・資料を使わない
2. 事実かどうかは問わない。「Aと書いてある」「Bと書いてある」「AとBは食い違う」だけを問題にする
3. 食い違いの可能性があれば、確信が無くても ⚠️ で報告する

## 入力

- 必須：対象ページ1件
- 任意：対象の節、意図した非対称（例：「ワインと果汁で非対称なのは意図的」）

## 1. 対象を抜き出す

| カテゴリ | 抜き出すもの |
| --- | --- |
| 用語の定義 | 「Xとは〜」「X＝〜」、略語・専門用語 |
| 数値・範囲 | 同じ対象についての、複数の箇所の数値 |
| 尺度の向き | 「1＝弱い／5＝強い」など向きのある順序 |
| 表の行どうし | 各行が同じ論理の形で書かれているか |
| 採用・不採用の理由 | 採った理由と採らなかった理由が両立するか |
| 前後のつながり | 「AだからB」「BだからC」が成り立つか |
| 分け方 | 漏れなく重ならないか |
| 参照先 | 「§Xを参照」「下の表」が実在するか |
| 本文とサブページの誘導 | 「詳しくは〜」の誘導文と、参照先の中身が合っているか。深掘りする理由が書いてあるか |
| ページをまたぐ正本 | 同じ概念が複数のページで本格的に説明されていないか。正本を1か所に決め、ほかは参照にする |
| 文献の使い方 | 本文に文献名がそのまま書かれていないか（メンションにする）、1ページに文献が多すぎないか（10件超、引用回数が中央値の3倍以上） |

## 2. 食い違いを見つける

| パターン | 例 | 判定 |
| --- | --- | --- |
| 定義のぶれ | 「渋み」をA節では収斂感、B節では苦味込みで使う | ⚠️ |
| 数値の不一致 | 同じ対象の温度がA節で12〜14℃、B節で10〜12℃ | ❌ |
| 尺度の向きの反転 | 「1＝弱い」と言いながら表では「1＝強い」 | ❌ |
| 表の非対称 | 「ワイン列」と「果汁列」の対応が行ごとに崩れる | ⚠️（意図の宣言が無ければ） |
| 採用・不採用の破綻 | Xは「訓練なしでは再現性が低い」と不採用、同じ条件のYは採用 | ⚠️ |
| 論理の飛躍 | AとBのつながりが成り立たない | ⚠️ |
| 分け方の漏れ・重なり | 分類がMECEでない | ⚠️ |
| 参照切れ | 「§3.2を参照」が無い | ❌ |
| 単位の不統一 | 同じ対象で ℃ と ℉、mg/L と µg/L が混ざる | ⚠️ |
| 誘導と中身の不一致 | 「サブページの§6を参照」に§6が無い・中身が違う | ❌ |
| 誘導の動機が無い | 「〜参照」だけで、なぜ読むべきかが無い | ⚠️ |
| 正本の重複 | 同じ概念が2つのページで詳しく説明されている | 🟠 |
| 文献名のべた書き | 本文に「著者 年」などがそのまま。登録済みならメンション漏れ、未登録なら登録か削除の候補 | ❌ |
| 文献が多すぎる | 主な文献にまとめられる補助の文献が多い | 🟠 |

意図した非対称が宣言されていれば✅。宣言が無ければ ⚠️ で利用者に判断を求める。表の対称を求めすぎない（中身が本来非対称なこともある）。

## 3. 修正案（書き換えない）

直し方は3つ：**一方にそろえる**（どちらを正とするかは利用者が決める）／**違いをはっきり書く**（意図した違いなら注記を足す）／**構造を変える**（表の列を足す、分け方を作り直す）。

## 4. 最終レポート

verification-basics の形。🔴＝❌、🟠＝⚠️、🟡＝確かめられない・保留、✅＝整合。付録に、宣言の無い非対称の一覧と網羅の宣言を入れる。
