# podcast_episodes（ポッドキャストの回）

聞いた・聞きたいポッドキャストの回を1行1回で貯めるDB。research プラグインの podcast-notes スキルが読み書きする。各自のNotionに置き、共有しない（書き起こしは番組の著作物のため）。

| プロパティ | 型 | 区分 | 中身 |
| --- | --- | --- | --- |
| タイトル | タイトル | 必須 | 回のタイトル。受け付け直後は仮でURL |
| URL | URL | 必須 | 回のURL（Pocket Casts / Apple Podcasts / 音声直リンクなど） |
| 状態 | ステータス | 必須 | 受付（未着手）→ 文字起こし中・文字起こし済（進行中）→ 解説済（完了）。失敗は エラー（未着手） |
| 番組 | セレクト | 必須 | 番組名。無ければ選択肢を足す |
| 配信日 | 日付 | 必須 | |
| 長さ（分） | 数値 | 共通・任意 | |
| ゲスト | テキスト | 共通・任意 | 名前と肩書き |
| テーマ | マルチセレクト | 共通・任意 | 分野。既存の選択肢を優先し、無ければ足す |
| 一言まとめ | テキスト | 必須 | その回を一文で |
| 文字起こし | URL | 必須 | 各自の非公開リポジトリの transcript.md |
| 知識コモンズ | URL | 共通・任意 | 知識コモンズの参考文献に載せたときの、そのページ |
| メモ | テキスト | 共通・任意 | 本人の感想・問い。エラーのときは理由 |
| 追加日 | 作成日時 | 共通・任意 | |

ページ本文には解説を書く（型は podcast-notes スキルの references/page-template.md）。
